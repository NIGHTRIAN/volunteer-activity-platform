# 志愿活动 App 使用说明（简单版）

> 这个 App 用来做两件事：**发布志愿活动**、**现场签到**。
> 装哪个 App 取决于你是哪一种人。

---

## 一、先装对 App

手机上要装的是**两个 App 中的一个**：

| 你是 | 装这个 | 图标名字 |
|---|---|---|
| **志愿者**（去参加活动的人） | 用户端 | 志愿活动 |
| **发布者**（组织活动的人） | 管理端 | 志愿活动 · 管理端 |

> 两个都装也可以，互不影响。

---

## 二、第一次打开：先选一种方式

打开 App 后，会先看到一个 **「怎么开始用」** 的弹窗，
里面按「你是志愿者 / 你是发布者」分别列了要做哪几步。照着点就行。
（勾选「不再提示」后不再打扰；之后可从「服务器地址」里的
「怎么开始用？」重新打开。）

然后点 **「服务器地址」**，二选一：

### 方式 1：只想先看看 → 用「本机演示模式」

点 **「使用本机演示模式（无需服务器）」**。

- ✅ 不用连任何服务器，立刻能用
- ⚠️ 数据只存在这台手机上，**不会同步给任何人**，也不与网页互通
- 适合：想先熟悉一下界面、给人演示

演示时的填写内容：

- 管理端：邀请码填 **`1111`**
- 志愿者：绑定页会**直接显示**该填什么（活动编号、学号、邀请码），照着填即可

### 方式 2：真的要用 → 连服务器

1. 问发布者要**服务器地址**（一般长这样：`192.168.1.5:8080`）
2. 点「服务器地址」→ 填进去 → 点 **「测试连接」**
3. 显示连接成功后，点 **「保存」**

> 地址填一次就记住了，以后不用再填。
> 连接失败最多等 6 秒就给结果，不会一直转圈。

## 三、志愿者怎么用（四步）

### 第 1 步：绑定活动

问发布者要三样东西：

- **活动编号**
- **你的学号**
- **邀请码**（一次性，形如 `BMJSL7XE`）

**最省事的填法**：发布者会把这三样拼成一段文字发给你，
直接点绑定页上的 **「粘贴邀请信息（自动填写）」**，三个框会自动填好。

也可以手动填 → 点 **「绑定并进入」**。

> 「选填：核对身份」那一栏可以填姓名或手机号后四位，填一个就行，不填也能绑。

### 第 2 步：签到

进到首页，点 **「去签到」** → **「开始签到」**。

手机会自动定位（会弹权限，选"仅在使用中允许"），然后连续取 3 次位置上报。

结果有三种：

| 看到 | 意思 | 要做什么 |
|---|---|---|
| **已签到** | 成功 | 不用管了 |
| **待确认** | 需要发布者看一眼 | 等发布者确认 |
| **未通过** | 位置不对或证据不足 | 看提示，靠近签到点再试 |

### 第 3 步：在岗确认

签到成功后，活动进行中会不定期要求"确认还在岗"。

底部 **「在岗」** 标签会显示任务，到了时间点 **「确认在岗」** 即可。

> ⚠️ 没到时间点不能提前点，超时了也不能补 —— 超时请联系发布者人工补录。

### 第 4 步：看记录

底部 **「记录」** 标签，可以看：

- 我的签到记录
- 在岗任务完成情况
- 还没上传成功的记录（联网后会自动补传）

## 四、发布者怎么用（五步）

### 第 1 步：登录

输入邀请码（默认 **`1111`**，具体问管理员）→ 点「登录」。

> 登录一次就够了，之后打开会记住这台手机。长期不用才会要求重新登录。

### 第 2 步：建活动

首页 → **「新建活动」**，填好这些：

| 项目 | 说明 |
|---|---|
| 活动名称 | 必填 |
| 组织部门 | 必填（网页筛选会用到） |
| 开始 / 结束时间 | 必填 |
| 活动地点 | 填一下比较好 |
| **位置（经纬度）** | **必填** —— 点 **「用当前位置」** 最省事 |
| 签到范围 | 默认 300 米，室内可改 150 |

**还有一项很重要：「场地网络」**

点 **「用当前网络作为场地网络」**（你要站在活动场地里点）。

> **为什么一定要点：**
> 不配这一项，志愿者每次签到都会变成"待确认"，你得一条条手工点通过。
> 配了之后，大部分人就能**自动通过**。

填完 → 发布。

### 第 3 步：加名单

活动详情 → **「名单」**。三种加人方式：

- 一个一个加：**学号 + 姓名**（学院、手机号选填）
- **在岗抽查**：建活动时可以选「自动抽查」（按间隔一直发）或
  「手动抽查」（你在看板上点一下才发）。活动进行中也可以随时点
  看板右上角的「手动抽查」临时点个名
- **从 Excel / CSV 文件导入**：直接选报名表文件，App 自动读出来
  （会自动跳过表头行；旧版 `.xls` 请先在 Excel 里另存为 `.xlsx` 或 CSV）
- 复制粘贴：从 Excel 里选一片单元格复制，粘贴到输入框

导入后都会先显示"已识别 N 行"，核对没问题再点导入。

### 第 4 步：发邀请码

名单页 → **「生成邀请码」**。

生成后会显示每个人的码，**点右侧的复制按钮**，复制到的
不是光秃秃一个码，而是**一整段**：

```
【志愿活动】图书馆书架整理志愿服务
活动编号：13
学号：2024001
邀请码：W8PWJXF4
```

> **参加下一个活动时**：先解除绑定，再输入新邀请码。
> 之前活动的记录会**留在手机里**（「记录」页底部、绑定页「我参与过的活动」），不会丢。

把这一整段发给本人，他在绑定页点「粘贴邀请信息」就能自动填好 ——
不用再一个个抄。

> 活动编号在名单页顶部**一直显示**，随时可以点旁边按钮复制；
> 邀请码明文只显示这一次，**一人一个，不要发混、不要贴群里**。

### 第 5 步：现场看板 & 确认

活动详情 → **「现场看板」**，能看到谁签到了、谁还没到。

有人显示 **「待确认」** 时，点他 → 看现场证据（位置、距离、精度、评分）→ 选 **「通过」** 或 **「驳回」**。

> 通过后名单会立刻变成「已签到」。

## 五、连不上怎么办

按这个顺序试：

1. **手机和电脑连的是同一个 Wi-Fi 吗？**
2. 用手机浏览器打开 `http://<服务器地址>/api/health`
   - 打不开 → 网络问题（问发布者）
   - 能打开 → App 里的地址填错了，重新填
3. **服务器的电脑防火墙**要允许 8080 端口
4. 换过 Wi-Fi 的话，**电脑的地址会变**，要在 App 里重新填

> 实在不行还有个土办法：用数据线连电脑，让发布者帮忙设一下。

## 六、常见疑问

**Q：网页上能签到吗？**
不能。网页只能看活动和导出名单，**签到和确认只能在 App 里做**。

**Q：网页能看到活动，为什么我手机上找不到？**
发布者登录后看到的是"**我发布的**活动"，只有他自己的。
网页是公开浏览，能看到所有人的。两者不一样，不是坏了。

**Q：签到一直显示"待确认"？**
多数是活动没配「场地网络」，告诉发布者补一下就行。
也可以看看结果里的"距签到点"——离得太远也会这样。

**Q：手机换了 / App 卸载了怎么办？**
找发布者**重新要一个邀请码**，重新绑定即可。旧手机的授权会自动作废。

**Q：定位权限必须给吗？**
必须。签到要证明你在现场。App 只在签到和在岗确认时取一次位置，**不会一直跟踪**。

**Q：演示模式里的数据是真的吗？**
不是。演示模式的数据只在这台手机上，不会上传、不同步，**不能当正式记录**。

## 七、两句话记住

1. **志愿者**：绑定 → 签到 → 看「在岗」→ 看「记录」
2. **发布者**：登录 → 建活动（记得点"用当前网络"）→ 加名单 → 发码 → 看看板

> 提示里一般会说明原因。
