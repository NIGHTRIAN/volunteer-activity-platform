# 手机连接指南（手机 → 这台电脑）

> 目标：在手机上装好两个 App，让它们连上**这台电脑**上的服务端。
>
> 全程大约 5 分钟。只需要在这台电脑上操作一次启动，之后手机记住地址。

---

## 第 0 步：先让电脑上的服务跑起来

双击 **`启动服务器.bat`**（一步到位：放行防火墙 + 启动服务 + 复制地址）。

首次双击会弹出一次 **"是否允许"**，点 **「是」**（这是放行防火墙，只需一次）。

然后窗口里会出现：

```
手机 App 服务器地址
http://192.168.1.23:8080/api
✓ 已自动复制到剪贴板，手机上直接粘贴即可
```

👉 **地址已经在电脑剪贴板里了，不用手抄、也不用在命令行里选字复制。**

> 这个窗口**不要关**，关了服务就停了。用完再关。

### 地址丢了怎么办

三个办法任选：

1. **再双击一次 `启动服务器.bat`** —— 不会重启服务，只会把地址重新复制到剪贴板
2. 打开包里的 **`服务器地址.txt`**
3. 看服务器窗口的**标题栏**（写着 `志愿活动平台 · http://IP:端口/api`）

如果窗口显示"未探测到局域网 IP"，说明电脑没连网络 —— 先连上 Wi-Fi 或网线，再重开。

---

## 第 1 步：手机和电脑要在同一个网络

必须满足以下**任一条**：

- 手机和电脑连**同一个 Wi-Fi**（最常见）
- 电脑插网线、手机连同一个路由器的 Wi-Fi

**不能用的组合**：手机用 4G/5G 流量、电脑连别的网络 —— 那样互相找不到。

> 校园网/公司网常见一个坑：同一个 Wi-Fi 下设备之间互相禁止访问
> （叫"客户端隔离"）。表现是网址在电脑上打得开、手机上打不开。
> 遇到就换一个网络（例如手机开热点、电脑连手机热点），见第 5 步排查。

---

## 第 2 步：安装两个 App

整合包里有 `web\dist\apk\` 文件夹，两个安装包在里面，传到手机上安装：

| 文件 | 给谁用 |
|---|---|
| `志愿活动-用户端.apk` | 志愿者（签到的人） |
| `志愿活动-管理端.apk` | 发布者（组织活动的人） |

**传到手机的三种方式，任选一种：**

1. **数据线**：手机连电脑 → 把 apk 复制到手机存储 → 手机上用文件管理器点开安装
2. **微信/QQ 文件传输助手**：发给自己 → 手机上点开安装
3. **手机浏览器直接下载**（最省事）：手机连好同一个 Wi-Fi 后，在手机浏览器里打开
   `http://<电脑IP>:8080/apk/志愿活动-用户端.apk`
   （`<电脑IP>` 换成第 0 步那个 IP；下载完点开安装即可）

> 只装一个也可以 —— 比如你只是志愿者，只装用户端就够。

安装时如果提示"未知来源应用"，选**允许**（这是自己打包的 App，没有上应用商店）。

---

## 第 3 步：把服务器地址填进 App

两个 App 都要做这一步，**做法完全一样**：

1. 打开 App
2. 右上角点 **「服务器地址」**（图标像一个插头/齿轮）
3. 在输入框里**长按 → 粘贴**（地址已经在电脑剪贴板里，形如
   `http://192.168.1.23:8080/api`）
4. 点 **「连接并测试」**

> 手输的话注意三点：开头是 `http://`（不是 `https://`）、结尾要带 `/api`、
> 中间是**电脑的 IP**（不是 `127.0.0.1`，那是手机自己）。

**成功的标志**：弹窗里显示"连接成功"，并且首页能正常显示活动列表。

填对后 App 会记住，以后不用再填。

> 如果这台电脑的 IP 变了（换网络、重启路由器），手机上要重新填一次。
> 想重新拿到地址：**再双击一次 `启动服务器.bat`**（会重新复制到剪贴板，
> 不会重启服务），或打开 `服务器地址.txt`。

---

## 第 4 步：验证能用了

### 作为志愿者（用户端）

1. 找发布者要三样：**活动编号、学号、邀请码**
2. 在绑定页点 **「粘贴邀请信息（自动填写）」** —— 发布者发来的整段文字会一键填好
3. 点「绑定并进入」
4. 首页点「去签到」

### 作为发布者（管理端）

1. 登录，邀请码默认 **`1111`**
2. 「新建活动」→ 点「用当前位置」→ 点「用当前网络」→ 发布
3. 「名单」→ 加人或「从 Excel / CSV 文件导入」
4. 「生成邀请码」→ 点复制，把整段发给本人
5. 「现场看板」看谁签到了

**都没问题的话，你在电脑浏览器打开 `http://127.0.0.1:8080/` 也能看到同一个活动** ——
手机和网页看到的是同一份数据，这就是"三端连通"。

---

## 第 5 步：连不上怎么办

按顺序排查，**每一步都能排除一类原因**。

### ① 手机能打开网页吗？

手机浏览器里打开：`http://<电脑IP>:8080/`

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 能打开网页 | 网络通、服务正常，问题在 App 里填的地址 | 检查是不是少了 `/api`、是不是写成了 `127.0.0.1` |
| 一直转圈/超时 | 防火墙挡了，或不同网络 | 先做 ② 和 ③ |
| 立刻报"打不开/无法访问" | 两台设备不在同一网络，或被"客户端隔离" | 做 ④ |

### ② 放行防火墙

**再双击一次 `启动服务器.bat`**，在弹出的窗口里点 **「是」**。

> 防火墙是启动器自动处理的，第一次双击时就会请求放行。
> 如果当时点了「否」，就再双击一次补上 —— 不需要单独的管理员脚本。
>
> 启动器底部会显示防火墙状态：
> - `防火墙  已放行` → 没问题
> - `防火墙  ⚠ 未放行，手机可能连不上` → 再双击一次并点「是」

### ③ 确认在同一个网络

- 电脑：`启动服务器.bat` 窗口里显示的 IP（如 `192.168.1.23`）
- 手机：设置 → WLAN → 点当前 Wi-Fi → 看"IP 地址"

两者**前三段要一样**（`192.168.1.x` 和 `192.168.1.y` 算同一网络）。
不一样就是没连到同一个路由器。

### ④ 换网络（对付"客户端隔离"）

校园网、宿舍网、公司网经常禁止同一 Wi-Fi 下的设备互访。

最省事的验证办法：**手机开热点，电脑连手机热点**。
这时电脑的 IP 会变（通常是 `192.168.43.x`），按第 0 步重新看窗口里的地址，手机重填一次。

### ⑤ 地址改了但 App 还在连旧的

App 右上角「服务器地址」里重新填新地址 → 点「连接并测试」。

如果 App 里还残留着旧活动、提示"需要重新登录"，先点「退出登录」再重新登录。

### ⑥ 还是不行

把下面这些信息记下来，能快速定位：

- `启动服务器.bat` 窗口里打印的「手机 App 服务器地址」
- 手机上填的地址（截图「服务器地址」弹窗）
- 手机浏览器打开 `http://<电脑IP>:8080/api/health` 看到的内容

正常情况下它应该显示类似：

```json
{"code":0,"msg":"成功","data":{"status":"ok","env":"prod", ...}}
```

## 附：这台电脑对外提供什么

| 地址 | 用途 |
|---|---|
| `http://<电脑IP>:8080/` | 网页端（浏览器打开，只读浏览） |
| `http://<电脑IP>:8080/api/...` | 接口（**手机 App 填这个**） |
| `http://<电脑IP>:8080/api/health` | 健康检查（排查时用） |
| `http://<电脑IP>:8080/apk/...` | 安装包下载（如果 apk 文件夹还在） |

## 附：安全提醒

这是一套**验收/演示用**的部署，开机即用，默认值如下：

- 管理员邀请码默认 `1111`
- 首次启动会写入 8 条演示活动

正式给一群人用之前，请在 `.env` 里改两处（改完重启）：

```
ADMIN_INVITE_CODE=换成一个别人猜不到的码
SEED_ON_START=false
```

另外：服务端没有 HTTPS，也**没有账号体系**（管理员凭邀请码登录）。
只适合校内小范围使用，不要放到公网上。
