# 部署说明（把任意一台 Windows 电脑变成服务器）

> 这个整合包**自带运行环境**：目标电脑不需要装 Node.js、不需要装数据库、不需要联网。
>
> **解压 → 双击 `启动服务器.bat` → 完成。**
>
> 一次双击会做完三件事：**放行防火墙**（只弹一次 UAC，点「是」）、
> **启动服务**、**把手机要填的服务器地址复制到剪贴板**。
>
> 所以手机上不需要手抄地址，直接粘贴即可。

---

## 一、包里有什么

```
志愿活动平台-服务器/
├─ 启动服务器.bat              ← 唯一的入口，双击它（防火墙已合并进来）
├─ 手机连接指南.md              ← 手机怎么连，给使用者看
├─ 部署说明.md                  ← 本文件
├─ 服务器地址.txt                ← 运行时自动生成/更新，可随时打开复制
├─ node/node.exe                ← 自带运行环境（不用另装 Node）
├─ server/                      ← 服务端程序
│  ├─ src/
│  └─ data/                     ← 数据库放这里（首次启动自动创建）
├─ web/dist/                    ← 网页端（由服务端直接托管）
└─ web/dist/apk/                ← 两个手机安装包（手机可从网页直接下载）
   ├─ 志愿活动-用户端.apk
   └─ 志愿活动-管理端.apk
```

**整个文件夹可以随便挪**（U 盘、桌面、D 盘都行），路径里有中文也没关系。
只要文件夹内部结构不变，就能跑。

## 二、部署步骤

### 1. 解压

把整个压缩包解压到一个**可写的**位置，例如 `D:\志愿活动平台\`。

⚠️ 不要放在 `C:\Program Files\` 这类需要管理员权限才能写的地方
（数据库要往 `server/data/` 里写文件）。

### 2. 双击 `启动服务器.bat`

- 会弹出一个黑色窗口，**这是正常的**，它就是服务器
- **首次运行**会自动生成 `.env` 配置文件，并请求一次防火墙放行
  （UAC 弹窗点「是」；这是唯一需要点一次的权限确认）
- 十几秒后会自动打开浏览器，显示网页

窗口里会显示：

```
手机 App 服务器地址
http://192.168.1.23:8080/api
✓ 已自动复制到剪贴板，手机上直接粘贴即可
```

- **手机要填**：上面那一行（结尾带 `/api`）—— **已经在剪贴板里了**
- 自己验收：`http://127.0.0.1:8080/`
- 给别人看：`http://192.168.1.23:8080/`（用 IP 那个）

地址除了在剪贴板里，还会写进 **`服务器地址.txt`**，
并且窗口标题栏也会显示 —— 三个地方都能拿到，不用在命令行里选字复制。

### 3. 停止

在窗口里按 **Ctrl+C**，或直接关掉窗口。

数据不会丢 —— 存在 `server/data/volunteer.db`。

## 三、常用操作

| 想做的事 | 怎么做 |
|---|---|
| 换端口（8080 被占用） | `启动服务器.bat -Port 8081`，或改 `.env` 里的 `PORT` |
| 不自动开浏览器 | `启动服务器.bat -NoBrowser` |
| 改管理员邀请码 | 改 `.env` 里的 `ADMIN_INVITE_CODE`，重启 |
| 不想要演示活动 | 改 `.env` 里 `SEED_ON_START=false`，并删掉 `server/data/` 后重启 |
| **再复制一次手机地址** | **服务已在跑时再双击一次 `启动服务器.bat`**：不重启服务，只把地址重新复制到剪贴板 |
| 单独修防火墙 | `启动服务器.bat -FirewallOnly` |
| 备份数据 | 复制 `server/data/volunteer.db`（先停止服务） |
| 换个电脑部署 | 整个文件夹拷过去，双击 `启动服务器.bat` 即可 |

> 需要"干净重来"时：关掉服务 → 删除 `server/data/` 文件夹 → 重新启动
> （会重新建库；首次启动会再写入 8 条演示活动）。

## 四、`启动服务器.bat` 允许的参数

```
启动服务器.bat -Port 8081        监听 8081
启动服务器.bat -NoBrowser        不自动打开浏览器
启动服务器.bat -FirewallOnly     只放行防火墙，不启动服务
启动服务器.bat -SkipFirewall     跳过防火墙放行（无人值守/已放行时用）
```

## 五、可能遇到的问题

### 窗口一闪就没了 / 提示"启动失败"

按提示操作。常见原因：

| 现象 | 原因 | 解决 |
|---|---|---|
| 找不到 `node\node.exe` | 解压不完整 | 重新解压整个包 |
| 提示"自带运行环境无法执行" | 杀毒软件拦截了 node.exe | 把整个文件夹加入白名单，或点"允许" |
| 提示"端口 8080 已被其他程序占用" | 有别的程序占了 8080 | `启动服务器.bat -Port 8081` |
| 浏览器打不开页面 | 服务还没起来 | 等 5 秒刷新；看窗口里有没有报错 |
| 提示"服务已经在运行中" | 这是**正常**的（不是错误） | 地址会重新复制到剪贴板；关掉旧窗口再启动可重启服务 |

### 忘记/丢了服务器地址

三个办法，任选：

1. **再双击一次 `启动服务器.bat`** —— 不会重启服务，只会把地址重新复制到剪贴板
2. 打开包里的 **`服务器地址.txt`**（每次启动自动更新）
3. 看服务器窗口的**标题栏**（显示为 `志愿活动平台 · http://IP:端口/api`）

### 网页能打开，但手机连不上

看 **`手机连接指南.md`** 的第 5 步，那里有完整排查顺序。

一句话版：**先确认手机和电脑同一 Wi-Fi，再确认防火墙已放行，最后排除"客户端隔离"**。

防火墙没放行成功的修法：**再双击一次 `启动服务器.bat`，在弹窗里点「是」**。
（启动器会自动处理，不需要单独的管理员脚本。）

### 这台电脑的 IP 变了

换网络后局域网 IP 会变。重启 `启动服务器.bat` 看新地址，手机上重填一次即可。
数据和服务端程序完全不受影响。

### 想放到公网 / 多人长期使用

**这个包不适合**。它没有 HTTPS、没有账号体系（管理员凭邀请码登录）、
数据库是单文件 SQLite。仅适合校内小范围、临时验收。

正式部署需要另做：HTTPS 反向代理、正式账号体系、MySQL、备份策略。

## 六、这套东西是什么

三部分，数据汇到同一处：

- **手机 App（两端）**：现场用。只有 App 能签到（需要定位证据）和复核
- **网页端**：电脑上浏览、筛选、导出。**只读**，不能签到
- **服务器（这个包）**：数据中枢，也是"这次签到算不算数"的最终判定方

App 只负责采集证据并上报，**不自己下结论**。

## 七、给验收者的最小验证路径

1. 双击 `启动服务器.bat`，浏览器打开网页 → 应看到 8 条演示活动
2. 网页点开任意活动 → 能看到详情、时间、地点、状态
3. 手机（同一网络）装管理端 App → 服务器地址填 `http://<IP>:8080/api` → 邀请码 `1111` 登录
4. 管理端「新建活动」→ 用当前位置 → 发布
5. 管理端「名单」→ 加一个人 →「生成邀请码」→ 复制整段
6. 手机装用户端 App → 填同一个服务器地址 →「粘贴邀请信息」→ 绑定 → 签到
7. 回到管理端「现场看板」→ 应看到这人「已签到」
8. 电脑网页刷新 → 能看到刚发布的活动（手机与网页是同一份数据）

跑通第 8 步，就说明三端确实连在同一个服务器上。

## 启动后会自动打开网页

双击「启动服务器.bat」后：

1. 第一次会弹一次 UAC，点「是」（放行防火墙）；
2. 服务起来后**自动打开浏览器**，显示活动列表 —— 不用手动输网址；
3. 那个命令行窗口要**一直开着**：关掉窗口 = 停止服务。

> 只是**点一下**那个窗口不会让服务退出（旧版本里点中窗口会让日志"卡住"，
> 已经关掉了那个容易误触的功能）。想复制窗口里的文字，看「服务器地址.txt」
> 或者本文件夹里的说明文件即可。

不想自动开网页：`启动服务器.bat -NoBrowser`
